# 컬러메이트 (Color Mate)

학생이 **퍼스널컬러 컨설턴트 · 메이크업 아티스트 · 패션 스타일리스트** 를 체험하는 학교 진로체험용 웹앱입니다.

## 활동 흐름

| 단계 | 화면 | AI 비용 |
| --- | --- | --- |
| 1 | 수업코드 + 이름 입력 | 0원 |
| 2 | 시각 선택 질문 10개로 퍼스널컬러 사전 예상 | 0원 (웹앱 내부 점수 계산) |
| 3 | 예상 결과 (온도 · 명도 · 채도 축) | 0원 |
| 4 | 선생님과 실제 드레이핑 (오프라인) | 0원 |
| 5 | 12타입 중 최종 타입 확정 | 0원 |
| 6 | 얼굴 + 어깨가 보이는 정면 사진 1장 준비 | 0원 |
| 7 | 메이크업 LAB (내 사진 위에서 디자인) | 0원 |
| 8 | 의상 · 신발 · 액세서리 스타일링 | 0원 |
| 9 | AI 최종 스타일 → Before/After → 컬러 프로필 | **OpenAI 이미지 생성 1회** |

유료 AI 호출은 마지막 `AI로 내 스타일 완성하기` 버튼 **1회**에서만 실행됩니다. 미리보기 단계에서는 어떤 AI API 도 호출하지 않습니다.

## 12타입 퍼스널컬러

봄(라이트 · 브라이트 · 웜), 여름(라이트 · 뮤트 · 쿨), 가을(뮤트 · 웜 · 딥), 겨울(브라이트 · 쿨 · 딥) 12타입을 운영합니다.
타입마다 대표 팔레트 · 추천 립 · 블러셔 · 아이섀도 · 의상 색 · 온도 · 명도 · 채도 · 키워드가 각각 다르게 정의되어 있습니다. (`src/data/personalColors.ts`)

추천색에는 `★ 내 타입 추천` 표시가 붙지만 **다른 타입 색도 자유롭게 선택**할 수 있습니다. 추천색과 다른 색을 직접 비교해 보는 것이 활동의 목적입니다.

## 교사용 화면

- `/expert` — 교사용 관리센터 (4자리 비밀번호)
- `/settings` — OpenAI 이미지 API 설정

관리센터에서 **학교 / 기관명 + 반 / 회차** 를 입력해 수업코드를 여러 개 만들고 복사 · 삭제할 수 있습니다.
수업코드는 현재 브라우저의 `localStorage` 에 저장되며, 저장 구현은 `src/services/classSessions.ts` 의 `ClassSessionStore` 인터페이스 뒤에 분리해 두어 나중에 서버 저장으로 교체할 수 있습니다.

교사가 학생의 퍼스널컬러를 미리 등록하는 기능은 없습니다. 학생이 직접 예상하고 드레이핑으로 확인한 뒤 확정합니다.

### 수업 자료 슬라이드

관리센터 맨 위 **수업 자료 슬라이드 열기** 로 들어가면 `/lesson` 에서 40장짜리 수업 슬라이드를 바로 진행할 수 있습니다. 파일을 내려받지 않고 웹앱 안에서 옆으로 넘기는 방식입니다.

| 트랙 | 장수 | 내용 |
| --- | --- | --- |
| 수업 열기 | 6 | 세 직업의 관계, 색이 하는 일, 오늘 활동 8단계, 활동 약속 |
| 퍼스널컬러 컨설턴트 | 10 | 온도·명도·채도 3축, 웜/쿨 비교, 드레이핑 관찰법, 상담→진단→제안→기록 |
| 메이크업 아티스트 | 10 | 일하는 현장, 얼굴 위 작업 순서, 위치·질감·강도, 조명과 카메라 |
| 패션 스타일리스트 | 10 | TPO, 팔레트 안에서 고르기, 실루엣·소재, 액세서리 |
| 수업 마무리 | 4 | 예상과 실제가 달랐다면, 공통 역량, 색으로 일하는 다른 곳 |

- 학생과 함께 푸는 **퀴즈 8개** — 보기를 고르면 정답·오답 모두 이유가 나오고 다시 풀 수 있습니다.
- **교사 노트**(발문·진행 팁)는 기본으로 숨겨져 있고 상단 버튼으로 켭니다.
- 조작: 좌우 버튼 · 키보드 `←` `→` `Space` `Home` `End` · 터치 스와이프 · 하단 점 이동 · 주제별 바로가기 · 전체화면.
- 슬라이드 이미지는 그려 넣지 않고 **실제 앱 화면**(`public/lesson`)과 **카탈로그 상품 사진** 만 씁니다. 색 팔레트는 12타입 데이터를 그대로 불러오므로 데이터가 바뀌면 슬라이드도 함께 바뀝니다.

#### 한글 파일로 저장

상단 **한글 파일** 버튼을 누르면 슬라이드 40장 전체가 `컬러메이트-수업자료.hwpx` 한 개로 내려받아집니다. 한글 2014 이상에서 바로 열리고, 인쇄해서 수업 계획을 세우거나 필요한 부분만 골라 학습지로 고쳐 쓸 수 있습니다.

- 슬라이드 제목 · 본문 · 불릿 · 12타입 팔레트 이름 · 퀴즈(보기 ①②③④ · 정답 · 오답 이유) · 교사 발문까지 문단 365개가 그대로 들어갑니다.
- 문서 내용은 `data/lesson*` 에서 만들어지므로 슬라이드를 고치면 저장되는 문서도 같이 바뀝니다. 따로 관리하는 원고는 없습니다.
- 파일은 브라우저 안에서 만들어집니다. 서버로 아무것도 보내지 않고, 만드는 순간에만 관련 코드를 내려받습니다(첫 화면 용량에 영향 없음).
- 저장 형식은 한글 공개 문서 표준인 **HWPX**(KS X 6101) 입니다. 예전 이진 형식인 `.hwp` 는 공개된 규격이 없어 브라우저에서 만들 수 없습니다. `.hwpx` 로 열어 **다른 이름으로 저장 → `.hwp`** 를 고르면 예전 형식으로도 바꿀 수 있습니다.

## OpenAI 설정

API 키는 브라우저 입력창이나 `VITE_` 환경변수에 넣지 않습니다. Vercel 프로젝트의 **Settings → Environment Variables** 에 등록한 뒤 재배포하세요.

```text
OPENAI_API_KEY=발급받은 OpenAI API 키
SETTINGS_PIN=교사용 4자리 비밀번호
SETTINGS_ENCRYPTION_KEY=24자 이상의 길고 예측 불가능한 임의 문자열
OPENAI_IMAGE_MODEL=gpt-image-1.5
OPENAI_IMAGE_QUALITY=medium
OPENAI_IMAGE_SIZE=1024x1536
```

`/settings` 화면에서 저장한 키는 암호화된 HttpOnly 쿠키에 보관되며 저장에는 `SETTINGS_ENCRYPTION_KEY` 가 필요합니다. 여러 기기에서 학생이 접속하는 운영 방식이라면 서버 환경변수 `OPENAI_API_KEY` 를 사용하는 편이 안정적입니다.

## 사진 촬영

필요한 사진은 **얼굴 + 어깨가 보이는 정면 사진 1장** 입니다. 전신사진은 요구하지 않습니다.

- 미리보기 위에 **4:5 촬영 영역 · 얼굴 타원 · 눈높이 눈금 · 어깨 곡선** 가이드가 표시됩니다.
- 얼굴을 실시간으로 인식해 `조금 뒤로 / 조금 앞으로 / 가이드 안으로 / 정면을 봐주세요 / 더 밝은 곳` 을 안내하고, 자세가 맞으면 3초 뒤 자동으로 촬영합니다. (자동 촬영은 끌 수 있습니다)
- 촬영·업로드한 사진은 얼굴 위치를 기준으로 **자동으로 4:5 인물 구도** 로 정리됩니다. 학생이 완벽하게 맞출 필요는 없습니다.
- 얼굴 인식 파일(wasm · 모델)은 빌드 시 `public/mediapipe` 로 준비되어 자체 호스팅되므로 외부 CDN 이 막힌 학교망에서도 동작합니다. 실패하면 CDN 으로 자동 대체하고, 그래도 안 되면 고정 가이드만 사용합니다.

### 화질

- 카메라는 세로 해상도를 지정하지 않고 가로 해상도만 요청합니다. 세로형 해상도를 요청하면 브라우저가 센서 화면을 **잘라내** 화각이 크게 좁아지기 때문입니다.
- 카메라 zoom 제약의 최솟값은 보통 1.0(=줌 없음)이라 화각을 더 넓힐 수 없습니다. 4:5 구도는 촬영 뒤 캔버스에서 만듭니다.
- 미리보기 캔버스는 화면 배율(devicePixelRatio)에 맞춰 그리고, 없는 디테일을 만들어내는 확대 보정은 하지 않습니다.
- 노트북 웹캠 해상도가 낮으면 휴대폰으로 찍은 사진을 업로드하도록 안내합니다.

## 개인정보

- 사진은 브라우저 메모리에만 두고, 마지막 AI 생성 1회에서만 API 로 전송합니다.
- 최종 이미지는 얼굴 · 헤어 · 피부톤을 유지하며, 사진에 없는 몸은 학생 연령에 맞는 자연스러운 비율로 구성합니다. 실제 키나 체형을 재현하지 않습니다.

## 화면 구조

```
src/
  data/         12타입 · 질문 · 메이크업 · 의상 카탈로그 · 활동 단계 정의
  face/         카메라 제어, 얼굴 인식, 촬영 구도 계산(가이드 · 자동 크롭)
  data/lesson*  교사용 수업 자료 슬라이드 내용 · 타입 · 한글 문서 변환
  services/     수업코드 저장소, 학생 세션 저장
  screens/      화면 단위 컴포넌트
  components/   공용 UI (활동 진행바, 색상칩, 촬영 가이드, 메이크업 미리보기 캔버스)
  styles/       tokens → base → components → screens (@layer 로 우선순위 고정)
  lib/          한글(HWPX) 문서 생성기와 ZIP 작성기
  types/        표준 DOM 타입에 없는 카메라 제어 항목 선언
api/            Vercel Functions (최종 이미지 생성 · 설정)
scripts/        빌드 전 얼굴 인식 파일 준비
```

## 반응형

`src/styles/tokens.css` 한 곳에서 브레이크포인트별 폭 · 여백 · 글자 크기 토큰을 정의하고, 화면 CSS 는 토큰만 사용합니다.

| 구간 | 폭 | 레이아웃 |
| --- | --- | --- |
| 모바일 | ~767px | 1열, 본문 14~16px |
| 태블릿 | 768~1179px | 좌우 여백 32px, 필요한 곳 2열, 본문 15~17px |
| 노트북 이상 | 1180px~ | 콘텐츠 최대 1320~1480px, 스튜디오 2열(사진 / 컨트롤), 본문 16~18px |

한글 가독성을 위해 전역으로 `word-break: keep-all`, `overflow-wrap: break-word` 를 적용하고 제목은 `text-wrap: balance`, 본문은 `text-wrap: pretty` 를 사용합니다. 강제 `<br>` 줄바꿈은 사용하지 않습니다.
